# Contributing to Unitseek MDM

Thanks for helping improve a lightweight, self-hosted Android Enterprise device manager.

## Before opening an issue

- Search existing issues first.
- Do not include device identifiers, enrollment tokens, passwords, API keys, service-account JSON, or customer data.
- Use [SECURITY.md](SECURITY.md) instead of a public issue for a potential vulnerability.

## Pull requests

- Keep each pull request focused and explain the problem it solves.
- Add or update tests when behavior changes.
- Run the backend tests and `npm run build` in `frontend/` before requesting review.
- Keep UI text in English and do not add credentials or real customer configuration to the repository.
